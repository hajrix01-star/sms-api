# SMS API

تطبيق Android صغير لاختبار استقبال رسائل SMS الجديدة من مرسلين تختارهم.

## إصدار الاختبار المحلي 0.8

- لا يوجد API أو Webhook أو اتصال إنترنت.
- لا يرسل التطبيق أي رسالة أو بيانات خارج الجوال.
- يلتقط فقط الرسائل الجديدة بعد التفعيل، ومن المرسلين المطابقين لما أضفته. لا توجد خدمة تعمل باستمرار: يوقظ أندرويد التطبيق عند وصول الرسالة ثم ينتهي فورًا.
- يعرض سجلًا محليًا لآخر 200 رسالة مطابقة لتأكيد أن إذن SMS والاستقبال يعملان.
- يستطيع استيراد الرسائل السابقة المطابقة حتى تاريخ تختاره، بعد إذن صريح بقراءة SMS.
- يستطيع تصدير آخر 200 رسالة غير أمنية لكل مرسل تختاره في ملف JSON لعينة بناء القواعد.
- يستبعد رسائل OTP والأمن بالكامل من السجل والاستيراد وملف العينة؛ ولا يفتح مشاركة الملف إلا عندما تضغط زر التصدير.
- يوجد فحص تعافٍ اختياري، متوقف افتراضيًا، يراجع آخر 48 ساعة مرة تقريبًا كل 24 ساعة بجدولة أندرويد. لا يثبت التطبيق في الذاكرة ولا يحدد ساعة ثابتة.

## خطوات الاختبار

1. للبنوك أضف اسم المرسل كما يظهر في SMS. وللأشخاص أضف آخر 6–8 أرقام من الرقم الحقيقي، لا اسم جهة الاتصال.
2. اضغط **تفعيل استقبال SMS للاختبار** واسمح بإذن الرسائل عندما يطلبه Android.
3. أرسل رسالة عادية من الجوال الآخر إلى هذا الجوال.
4. افتح التطبيق وتحقق من ظهورها في **سجل الاستلام**.

فحص التعافي ليس بديلًا للاستقبال المباشر؛ هو شبكة أمان فقط إذا فات استقبال نادر. فعّله فقط بعد منح `READ_SMS` إذا رغبت فيه.

لا يتعامل التطبيق مع واتساب أو تيليجرام أو خدمات إمكانية الوصول.

## الإذن المطلوب

| الإذن | السبب |
| --- | --- |
| `RECEIVE_SMS` | استقبال رسائل SMS الجديدة المطابقة للمرسلين الذين تحددهم. |
| `READ_SMS` | استيراد الرسائل السابقة يدويًا حتى تاريخ تختاره. |
| `RECEIVE_BOOT_COMPLETED` | إعادة تسجيل فحص التعافي الاختياري بعد إعادة تشغيل الجوال. |

بعد نجاح هذا الاختبار نضيف ربطًا آمنًا مع Baseer Relay API، ثم يقوم الخادم بإرسالها إلى Odoo أو Telegram.
